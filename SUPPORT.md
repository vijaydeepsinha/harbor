# Support

Harbor is an open-source project maintained on a best-effort basis.

## Questions and usage help

Open an issue with the relevant configuration, Harbor version, Node.js version,
and a minimal reproduction. Do not include access tokens or private service
details.

## Bugs and feature requests

Use the issue templates in `.github/ISSUE_TEMPLATE/`.

## Security issues

Do not report vulnerabilities publicly. Follow the private disclosure process
in [`SECURITY.md`](SECURITY.md).

## Supported versions

Only the latest 1.x release receives fixes. Older versions may require upgrading
before a fix can be provided. Governance APIs marked experimental in
[`API_STABILITY.md`](API_STABILITY.md) may change in a minor release.
